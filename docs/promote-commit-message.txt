OG renderer WebP-incompatibility fix (Option B):
The dynamic /api/og endpoint was feeding the new WebPs to @vercel/og 0.11.1
(Satori), which throws "u2 is not iterable" on certain WebP encodings. Fix:
read the pre-built static og/<condition>.jpg files (JPEG) instead of source
WebPs. Loss of time-of-day variation in dynamic OG cards is invisible to
users — social platforms cache one preview per shared URL for ~30 days, so
time-of-day variation never reached them anyway.
