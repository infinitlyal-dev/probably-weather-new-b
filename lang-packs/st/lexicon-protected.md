# Sesotho — protected lexicon (confirmed-correct words; never "improve" these)

Words a native speaker CONFIRMED. The drafter treats these as fixed vocabulary — reuse them,
never swap them for a "better" synonym the model prefers. The outsider is wrong until a native
says otherwise (the imbatata rule — see zu/lexicon-protected.md #1, the cross-pack anchor).
