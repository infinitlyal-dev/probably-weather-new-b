# Sesotho — protected lexicon (confirmed-correct words; never "improve" these)

Words a native speaker CONFIRMED. The drafter treats these as fixed vocabulary — reuse them,
never swap them for a "better" synonym the model prefers. The outsider is wrong until a native
says otherwise (the imbatata rule — see zu/lexicon-protected.md #1, the cross-pack anchor).

| Concept | Protected Sesotho | Do NOT use |
|---|---|---|
| wind gusts | meea e fokang ka sefutho | lifofane (=airplanes) |
| thunder | modumo wa seaduma | modumo wa leholimo |
| Milky Way | Molalatladi | Tsela ea Lebese (calque) |
| fog / mist | moholi | mohodi (misspelling) |
| hot (it's hot) | ho chesa | ho tjhesa |
| respect (verb) | hlompha | hlonepha (Zulu/Xhosa form) |
| sunscreen | setlolo sa letsatsi | setofo (=stove) |
| sunrise | ho chaba ha letsatsi | mafube (stiff) |
| sunset | ho likela ha letsatsi | letsatsi le likela (stiff) |
| cricket (insect) | tswiritswiri | tsie (=grasshopper) |
| owls | merubisi | dikgogo (=chickens) |
| soup | sopho | soupa |
| biltong (the food word) | sehwapa | — |
| severe weather | boemo ba leholimo bo matla | leholimo le lebe |
| overcast | ho aparetse ka maru | maru (bare) |
| chilly | ho phodile | ho bata |
| low visibility | ponahalo e tlase | pono e tlase |
| feel sorry for | utloela bohloko | utsoarela (=forgive) |
| beautiful (weather/thing) | hotle | motle (=beautiful person) |

**Dialect anchor:** SA-Sesotho spelling — `joalo`/`joale` (not Lesotho `jwalo`/`jwale`).
**Register anchor:** code-switched loans (jersey, takkies, braai, Southeaster, lekker koud,
Toyota, place names) are protected TOO — keep them, they are the voice.
